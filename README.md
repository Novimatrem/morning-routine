# morning-routine

Based on some code I wrote for [https://gitlab.com/Novimatrem/direct-input-bash-game](https://gitlab.com/Novimatrem/direct-input-bash-game) but for displaying the steps of my morning routine 1 by 1. Controls are ``w`` and ``s``.

# Windows version

Ensure you have installed the required dependency: Git Bash (https://github.com/git-for-windows/git/releases)

Then run morning-routine\run-background-win.vbs
